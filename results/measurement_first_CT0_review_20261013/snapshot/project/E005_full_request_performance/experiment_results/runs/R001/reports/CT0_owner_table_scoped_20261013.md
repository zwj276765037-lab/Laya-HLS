# CT0 32-entry owner table: scoped hardware result

2026-10-13; M004/SM005/E005/R001. CT0 is an independent diagnostic of one original-capacity `FullOwners.record[32]` path. It implements only REQUIRE, ACQUIRE, and RELEASE_READ, and has no production owner, publisher, or retirement authority.

**Scoped result: host/original-helper and actual generated RTL PASS.** The generated top stores all 32 records at 5009 semantic bits each in an indexed one-port table module. Actual 512-bit FIFO input/output ports carry complete command/response packets in 12/11 beats. Vitis 2025.2 HLS generation finished in 154.489 s (peak owned RSS 2,914,260 KiB; child 0; guard trigger null). Its diagnostic estimate is BRAM18 8, DSP 1, FF 49,533, LUT 39,937, URAM 0 at a 150 MHz target; no physical result is available.

The original `FullRuntime` helper supplied an independent software reference. The normal case read all 32 cold defaults, loaded and read back 32 complete records, then compared 16 REQUIRE/ACQUIRE/RELEASE_READ outcomes and full post-operation records, including both coverage maps. Six operations committed; rejects left records unchanged. The finite generated RTL consumed 131 complete commands (1,572 input beats) and produced 131 complete responses (1,441 output beats) matching the checked trace. It took 73,429 diagnostic cycles, including INIT, serialized fixture traffic, output responses and testbench backpressure; 617 cycles had a response pending while the output FIFO was blocked. Separate request-valid-off and model-header-valid-off cold cases each matched nine commands in 5,073 cycles and showed one actual old-reader RELEASE_READ commit despite inactive context and a stale record identity. This confirms the original release rule is narrower than REQUIRE/ACQUIRE in the tested scope.

The one HLS source repair was prompted by a concrete Vitis failure: AT005 rejected aggregate diagnostic FIFO ports above 4096 bits. Splitting the same full command/response into 512-bit beats yielded AT006 generated RTL. AT004, AT007 and AT010 were runner preflight stops before their respective heavy tool stages; their records are preserved. AT008/AT009/AT011 are earlier limited RTL passes; AT012 is the final affected finite replay with corrected blocked-response counting and stale-identity negative cases. AT012 full xsim took 8.59 s, peak owned RSS below 1 GiB; static, pilot and all three full/negative sims ended child 0 with no guard trigger.

CT0 does not measure production control latency. Its 73,429 cycles include 131 diagnostic round trips and controlled stalls. The HLS utilization is not a joint resource or physical timing result.
