## Implemented source boundary

[c1_reserved_store.sv](../rtl/c1_reserved_store.sv) is the sole live RTL shell. It has one clocked metadata writer, Q64 and D4 payload arrays, an arithmetic return **without ready**, a registered result commit read, a registered READY-only trace read, pre-edge issue credit, and matching trace ACK retirement. It writes one 1299-bit result vector and, when reserved, one 256-bit selected trace on each valid matching return edge. Commit and writer backpressure do not gate that return write. Invalid returns, commits, issues, or ACKs set a sticky protocol error and trigger a simulation fatal. Reset covers metadata only; the integrating controller must require quiescent drain before reset.

The shell's source-declared logical storage is **91,860 bits**: Q64 payload 83,136; Q64 state/owner/head/count 5,217; D4 payload 1,024; D4 state/owner/head/count 215; tile hazards 678; registered result commit read 1,306; registered trace send read 276; return observation 7; protocol error 1. The original Q64 payload-plus-state figure is 83,264 bits (`64 × (1299 + 2)`); the 5,089 other Q64 metadata bits are separate. [storage_ledger.json](storage_ledger.json) records each first-use/reset rule and keeps writer service intent, the 56,663-bit unfinished arithmetic FIFO proposal, and the inherited 49,193,472-bit bank payload proposal outside the implemented shell total. Generated registers, RAM choice, physical port mapping, DSPs, latency, II, frequency, and utilization are **UNMEASURED**.

The exact shell port groups, Q64/D4 state transitions, per-edge payload-port roles, and missing integrations are in [interface_contract.json](interface_contract.json). [source_lists.json](source_lists.json) separates the live RTL shell, inherited arithmetic helpers, the independent HLS writer source, dormant probes, fail-fast adapters, and functional reference. There is **no live arithmetic translation unit or generated arithmetic service** in v3. [c1_writer_service.cpp](c1_writer_service.cpp) is a separate three-port HLS source using depth-one 618-bit command and 37-bit ACK channels; its generated RTL and shell bridge remain **UNBOUND**. The stage-v2 `FinalReturn` type survives only as an uninstantiated helper; no v3 final-result stream, blocking `FinalReturn.write`, or software consumer loop is live.

## Dormant regression sources

The direct store probe reserves 64 entries, holds commit and trace writer sinks unavailable, returns all reserved records at the no-ready port, checks exact ordered commit payloads and counts, drains a trace on matching ACK, then exercises simultaneous issue/return/commit on distinct slots. Integer/product-tree, bank-return, and selected-route probes contain finite changing-tag drivers and scoreboards with bubbles and reset/drain. Their adapters terminate with explicit `UNBOUND_*` fatal messages. The inherited FP streaming probe names the same seven actual wrapper modules and retains unchanged finite-case bindings. The frozen case file defines the inclusive half-pattern range 0–65535, INT8 extrema, R0 finite cases, and prior full-dimension fixtures. These are **test source definitions**, not executed results.

## Static inspection and remaining gates

The v3 source was inspected against the release and the stage-v2 archive. The 1299-bit result packing is unchanged (`next_ps[0:1023]`, masks `[1024:1151]`, seq/tag/slot/trace/error fields `[1152:1292]`, active-dot count `[1293:1298]`). The shell has no `ret_ready` port or result-feedback FIFO. A pre-edge RESERVED slot is required for every return; RETURNED-to-commit and READY-to-trace registered reads occur on later edges. The source-level storage sum above reconciles exactly; it is not a mapped hardware measurement.
