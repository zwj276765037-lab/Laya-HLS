# C1 explicit write-response boundary: source contract

2026-10-09. Designer/reviewer: GPT-6 Astra / xhigh. This additive contract resolves the response-retirement gap in the immutable C1 design. It permits source preparation only. No compiler, HLS, RTL or physical invocation is released. The original C1 design, metadata_reset_v3 and accepted evidence remain unchanged.

## Selected interface and evidence

Use `hls::burst_maxi<uint32_t>` for the candidate top's `out0`, `out1` and `observed` arguments. Keep the six read arguments and the nine existing bundle names. The public hardware target remains the accepted nine AXI masters and dual AXI-Lite register/offset/width behavior; the changed C++ type is an internal source-interface choice, not evidence that generated ports or register offsets match. The candidate header and CPU callers must use the new type consistently; the simulation constructor accepts the corresponding bound memory pointer. No production caller or ABI changes are authorized.

The installed synthesis header `Vitis/common/technology/autopilot/hls_burst_maxi.h` maps `write_request(offset,len)` to `__fpga_maxi_write_req(&Ptr[offset], len)`, `write(value,mask)` to `__fpga_maxi_write`, and `write_response()` to `__fpga_maxi_write_resp(Ptr)` (lines 60–90). This is an explicit source operation for consuming a write response. The separately installed `Vitis/include/hls_burst_maxi.h` is a CPU simulation model: it tracks request/write/response queues and pops its response queue at lines 227–230. Its immediate return is not physical B evidence.

The response function returns void and does not expose BRESP bits. This design establishes response retirement, not an error-code-to-ABI mapping. Preserve the existing normal-OKAY endpoint assumptions and external protocol checks. Do not claim that SLVERR/DECERR are detected or recovered by this API. Any requirement to expose bus errors needs a separate interface design.

## Three independent finite writer processes

Each write bundle has one owning writer process, one command FIFO of depth 1 and one acknowledgment FIFO of depth 1. These processes must execute concurrently with the arithmetic/control process; a blocking `write_response()` is legal only inside that port's writer. A source function call or HLS DATAFLOW pragma alone is not proof of concurrency. If the actual top cannot instantiate these independent processes, stop at source/structure review instead of serializing the fixed-return arithmetic loop behind a writer.

Use explicitly packed command words of 618 bits: word_offset[64], count[5], kind[3], trace_slot[2], sequence[32], payload[512]. Pack the fields in that order, least significant field first, with compile-time packing assertions. count is 1–16 for a write; unused payload words are semantically irrelevant. kind encodes quant-Q=0, quant-scale=1, group-trace=2, final-output=3, report=4 and EOS=7; 5/6 are invalid. trace_slot is meaningful only for group-trace and is zero otherwise. EOS uses count=0 and performs no AXI request. Acknowledgment is exactly 37 bits: kind[3], trace_slot[2], sequence[32], in the same least-significant-first convention. Other kind values are invalid. Out0/out1 use only final-output and EOS; observed owns all trace and report traffic.

There is at most one unacknowledged logical command per port, from core command acceptance until core acknowledgment consumption. The core increments its per-port sequence only when it submits a command and holds the expected sequence/kind/slot. It accepts no new command on that port until the matching acknowledgment is consumed; same-edge acknowledgment credit is not reused. The command sequence starts at zero only after quiescent command-boundary initialization. The accepted finite descriptor bounds must prove no 32-bit wrap in one command. An unexpected/duplicate acknowledgment is a verification failure, never credit.

The writer reads one command, keeps its entire packet stable in one local packet register, issues exactly one `write_request(word_offset,count)`, emits exactly count words in order with all four byte enables, then calls exactly one `write_response()`. Only after that call returns may it emit the matching acknowledgment. No acknowledgment is produced at request, data or WLAST acceptance. The writer cannot consume a new command while its current acknowledgment is blocked. It retains no unbounded software list and does not use an unbounded simulation-only channel.

An EOS command is consumed only when that writer has no physical request/response debt; the writer emits its EOS acknowledgment and exits its command-scoped process. The top does not return until all writer processes join. EOS does not substitute for a pending write acknowledgment.

For structural accounting, the three depth-1 command/ack FIFOs hold 3*(618+37)=1965 bits; one additional full current-packet register per writer adds 1854 bits, for a declared baseline of 3819 payload/control packet bits. Writer state, word index, expected-token bookkeeping, stream implementation overhead, and any core staging register are additional explicitly itemized storage. Do not silently reuse the earlier Q/trace-only storage subtotal or hide these copies inside a stream. Existing result payload and four trace-slot payload widths remain unchanged.

## Core admission, return and ordering

The arithmetic/control process polls command availability and acknowledgment availability without blocking its fixed-latency return processing. A writer stall may block new issue through exhausted trace credit, but every previously reserved result/trace return must still be captured and ordered PS/lane_bad commit must remain live. Do not put a blocking stream write/read, port write or response wait on that return path.

A trace slot reaches READY only at successful physical PS commit, as already specified. In head order, the core can submit that slot's actual eight-word payload as a group-trace command and move READY to SENDING. It stays SENDING until the matching observed-port acknowledgment is consumed. Only then may it become FREE. Cancellation and strict ring order are unchanged. Return writes to one trace payload and writer reads from another slot remain independently supported. A copied command payload does not free its source trace reservation.

Quant Q and scale trace must use the same observed writer, with existing byte values/addresses/order; all quant-trace acknowledgments retire before linear issue begins. Group traces preserve their existing eight-word layout. Ordinary matrix outputs still use out0; op 0x30 retains the existing plane/head split and exact out0/out1 address calculation. The first writer candidate sends each final output as count=1. No coalescing/reordering across inactive or failing lanes is added. Counters and trace-final fields are updated exactly once per existing logical output; final ABI values must match the prior source. Bus acknowledgment bookkeeping is separate from arithmetic error/rank state.

Each m0 boundary waits for arithmetic valids, result slots, trace slots, pending output commands and all corresponding acknowledgments before PS/lane_bad reuse. Before final report construction, all non-report traffic and read-side work must be drained. Form the exact existing 256-word header and send it in sequential observed-port commands of at most 16 words, waiting for each matching acknowledgment. The final report acknowledgment precedes EOS/join and external done. `O_INFLIGHT=0` is not used as a substitute for physical debt tracking. Context stays locked until the top can assert done with all R/B debts zero.

## Address and reset semantics

`word_offset` is the original validated byte offset divided by four. Address addition, overflow checks, word order, useful-byte counts, output sentinels and all descriptor/status/trace layouts are unchanged. Do not add a stronger BO alignment restriction to avoid AXI boundary handling. A logical request of up to 16 words may straddle a 4 KiB boundary depending on the registered base address. The generated manual-burst adapter must split legal physical bursts and aggregate every resulting physical B response before returning the logical write_response. This must be established from generated control plus a boundary-crossing RTL case. If it cannot be established, stop and resubmit a narrower writer contract; never assume one logical request means one physical B.

Warm reset remains after quiescent drain only. Reset semantic FIFO state, sequence expectations, writer state and valids without clearing packet/result/trace payload RAM. No in-flight AXI reset, stale-response isolation or platform abort guarantee is added.
