## Single metadata writer and dual-port memory ownership

The RTL controller owns slot states, seq ownership, reservation/return/commit counts, ring pointers, hazards and trace FREE/RESERVED/READY/SENDING states in one coherent next-state calculation followed by one clocked update. Payload memories have distinct physical roles: one arithmetic-return write port and one registered controller/commit read port. Result commit never writes result payload; trace sending never writes trace payload. Write only on ret_valid. Read only when the pre-edge matching slot is READY; no speculative payload read from FREE/RESERVED slots. A same-edge return cannot become a same-edge read through combinational next-state visibility: earliest read uses the following edge. Require conflict assertions and exact per-clock bank/port schedule.

Issue reserves result and optional trace slots atomically from pre-edge credits. Returning slots remain occupied until their existing physical commit/output-enqueue obligations complete. Same-edge retirement cannot supply issue credit unless the original contract explicitly permits it; preserve the original pre-edge rule. Commit may stop for output command capacity, matching physical PS write/ack obligations or trace writer state, while return writes continue independently. The ring therefore absorbs already accepted work; only future issue is backpressured. Queue size/return distance, same-tile reuse and return-to-commit phasing remain UNMEASURED until actual service characterization supports the requested profile. Never use a C++ edge counter to prove those clocks.

For PS/lane_bad operand access, issue a bank read only for an active, successful lane needing old PS. g0 supplies canonical positive zero without reading old PS. Inactive/failed lanes produce explicit neutral/ignored operands with matching validity, never an uninitialized payload read later hidden by a mask. Keep PS/lane_bad numeric payload reset-free; metadata/first-write/read-valid dominance must be explicit. Preserve 32 bank ports and the original physical-commit same-tile hazard policy.
