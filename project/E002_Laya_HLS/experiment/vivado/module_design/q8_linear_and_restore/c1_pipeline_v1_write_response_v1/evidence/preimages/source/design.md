## Credits, PS hazards and first-error retirement

Issue requires context and A readiness, all selected bank request paths ready, tile not busy and post-commit guard clear, one free result slot, plus trace credit if the selected shape lane could emit trace. On one issue event atomically reserve both required slots, set busy, issue bank reads, copy A payload and advance the scheduler. lane_bad is synchronous: its returned mask combines with shape before semantic active/MAC/PS decisions. Every issue, including all-masked and failing vectors, owns one fixed return and one ordered commit. Result return has no ready input and may not wait for AXI, trace or commit.

The result slot payload is exactly1299bits: next_PS[32]1024; shape/active/success/failure masks32each; seq17,m0=4,g=7,tile10,last_g1,result_slot6,trace_reserved1,trace_slot2,error_valid1,error_key28,error_bad_element64,active_dot_count6. Its separate state uses2bits FREE/RESERVED/RETURNED (fourth illegal). Candidate register storage is64x1301=83264bits before pointers/guards/control; submit exact packing assertions and no hidden per-lane duplicate result queues. One reserved-index full-vector write and one oldest-slot combinational read are the candidate port contract; true register/BRAM realization and timing remain unmeasured. If choosing synchronous result RAM later, return-to-commit latency and queue formula must be resubmitted rather than silently changed.

Maintain free+reserved+returned=64, unique reservation, monotonically ordered commit and no same-edge newly freed credit reuse. commit requires oldest RETURNED data and real simultaneous PS-success/lane_bad-failure writes plus counters/error/trace updates. Clear busy only on this physical commit, then block all same-tile reads throughout c+1; earliest next issue is c+2. Scheduler m0→g→tile does not skip a blocked tile; N2/T1 and T<F wait safely. The invariant, not an assumed timer, controls admission.

Trace4slots retain full256bit payload with valid/state/tag. Return writes the reserved payload independent of AXI, then successful PS commit publishes READY; inactive/failing commit makes CANCELED. Head order is strict. SENDING becomes FREE only after all corresponding B responses. Provide independent full-payload return write and writer read paths. Each m0 boundary drains arithmetic,result,trace and output responses before PS/lane_bad reuse; final report B retirement precedes done. Metadata-only reset cancels semantic valids and resets bookkeeping after quiescent drain; no payloadRAM clear or in-flight AXI reset claim.

For every active dot count32MAC even if its current FP phase fails. Failed lane writes lane_bad and no current PS/trace; later groups skip it. Reduce returned errors by minimum original tuple(tile10,row4,column3,g_or_G8,phase3) with separate valid, not arrival order or bad_element. Keep original64bit bad_element separately and global minimum across allm0, including bias atg=G/phase0. Finish allowed independent work and preserve prior legal external writes on final INVALID.
