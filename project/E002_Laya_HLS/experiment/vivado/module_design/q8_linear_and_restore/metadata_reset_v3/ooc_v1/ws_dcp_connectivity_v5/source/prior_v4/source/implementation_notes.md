# Ws v4 implementation notes

The byte-frozen `design.md` and `semantic_property_contract.json` are authoritative. `tb/generate_contract_tcl.py` renders the 22 exact REF_NAME groups and 348 required semantic parameter names into `source/required_properties.tcl`. The extractor hashes that literal Tcl before opening the sealed DCP. No DCP property alias is authorized in this revision: if a required UNISIM parameter name is absent, empty, unsupported, truncated or raises a tool error, the instance retains an explicit `REQUIRED_PROPERTY_GAP`. Declaration defaults are never used as actual values. A type's exemplar `list_property` result is recorded only as diagnostic metadata; it is never copied to another instance.

Selected cells are sorted by NAME. The extractor batches REF_NAME, IS_PRIMITIVE, PRIMITIVE_TYPE and IS_BLACKBOX metadata, then batches NAME, REF_PIN_NAME and DIRECTION for each selected cell's pins. Every encountered primitive group is sorted by selected NAME, and a fresh batched NAME read is checked against the cell ID order before any parameter values are paired. Each required property is queried once for the exact REF_NAME group; only a failed or wrong-length required group/property query may fall back to per-cell reads. Empty returned list elements remain per-instance gaps. INIT and INITP vector widths are checked against the declaration; the exact returned word is hex-serialized without modifying its value.

The existing 11 normalized tables and graph ID/hex schema remain intact. Pin-object `get_nets -segments`, canonical aliases, selected incidence, cached driver-owner classification and explicit constant drivers remain. The new `phase_ledger.tsv` records start/completion, group sizes, query fallbacks, gap counts and completed table flushes. A timeout leaves partial outputs and no completion marker; an empty `issues.tsv` alone has no meaning. Global DSP/utilization and exhaustive clock-property diagnostics are outside the critical extraction path; earlier sealed reports and the unchanged OOC XDC are bound in the source packet. `ap_clk` count is still checked.

Static Tcl completeness, generated-contract equivalence, Python AST and synthetic TSV parser checks are source checks only. A future full graph plus structural audit would still leave all 8 × 20,992 × 16 effective-bit read/write mappings, high addresses, timing and board acceptance held until separately reviewed proof and measurements exist. No v4 Vivado execution or numerical evaluator is released.
