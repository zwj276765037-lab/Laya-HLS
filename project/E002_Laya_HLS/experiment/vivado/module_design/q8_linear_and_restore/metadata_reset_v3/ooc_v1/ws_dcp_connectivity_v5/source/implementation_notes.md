# Ws v5 source implementation notes

The Astra xhigh [design](design.md) and reviewed v4 [semantic contract](semantic_property_contract.json) define this source-only revision. [prior_v4/manifest.json](prior_v4/manifest.json) binds the exact v4 packet and eleven maintained files, each original and archive copy with equal bytes and SHA256. None of those files was edited in v4. The new source packet checks those identities again.

`tb/extract_ws_graph.tcl` retains v4's exact-bank cell, pin, boundary, alias, net-component and driver-owner tables. In one dormant checkpoint open it selects the eight exact bank roots, rejects duplicate selected names, and issues one `write_verilog -mode funcsim -write_all_overrides true -keep_vcc_gnd -cell` command per bank in the specified order. It logs each begin/completion, exact bank NAME/REF_NAME, file length, SHA256 and aggregate bytes. The eight files are capped at 64 MiB each and 256 MiB total. Missing DCP required properties remain raw `properties.tsv` rows and `REQUIRED_PROPERTY_GAP` issues; only these gaps may pass the pre-join structural audit. Any other extraction issue, timeout or export error is terminal. No property is filled from a declaration default.

`tb/funcsim_structure.py` tokenizes a restricted structural Verilog subset and rejects unsupported syntax. It records exact ASCII byte spans for parameter literals, module definitions, expanded hierarchy and primitive paths, named ports, bus selections, concatenations, and continuous aliases. Its union graph is capped and rejects recursive modules, duplicate names, implicit nets, unknown primitives, conflicting constants and width mismatches. The exact actual Vivado output syntax is untested.

`tb/join_funcsim_graph.py` has a default CLI that refuses actual evidence. Under a later gate, its imported join would first require a complete DCP graph structural audit, then independently read the hash-bound UNISIM port declarations for pin width/direction. It binds exact hierarchy and primitive names, REF_NAMEs, named pin sets, directions, indices, boundaries, constants and canonical net components. It retains separate raw DCP and raw functional parameter tables, literal spans and a net-component correspondence table. Required semantic values come only from a nonempty actual DCP property or an explicit export override; every nonempty pair must agree. The eight RAMB36E2 inversion settings require explicit known one-bit export values even if the DCP reports a value. Any missing, `x/z`, conflict, unsupported encoding, unbound hierarchy or external cone remains a failure or held gap. The root module rename is recorded with the exact bank binding; no approximate instance-name or same-type matching is allowed.

The accepted checkpoint and OOC constraint are read only and hash-bound. A *candidate*, not released, extraction route uses the existing 0.2-second owned-RSS guard: 12 GiB, 900 seconds, four CPUs, low CPU/I/O priority and MemAvailable strictly above 192 GiB. The source packet binds the launcher, guard, helper, command tools, DCP, XDC, manuals, UNISIM files and source inventory, and specifies fresh control/report roots. It does not invoke that route. Actual parser/join invocation is separately held; it must receive its own bounded command and independent gate after the export and graph identities are reviewed.

This is structural and parameter preparation only. Even a successful future join would not prove Ws capacity, address decode, write uniqueness, same-storage read selection, parity/cascade, reset/clock behavior, 150 MHz timing or board operation.
