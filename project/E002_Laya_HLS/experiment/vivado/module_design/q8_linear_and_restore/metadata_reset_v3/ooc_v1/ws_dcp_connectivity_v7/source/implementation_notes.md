# Ws v7 exact installed-glbl envelope implementation

The authoritative [v7 design](design.md) corrects only the first actual v6 join failure: the functional export contains the installed Vivado `glbl.v` support body after the bank's `endmodule`. [prior_v6_manifest.json](prior_v6_manifest.json) contains exact bytes, hashes, paths, and modes for all 15 listed v6 source preimages. The v6 sources, raw exports, graph tables, DCP and prior evidence remain unchanged. [v6_to_v7.diff](v6_to_v7.diff) is the literal maintained-source diff; the old v6 packet and retired packet generator remain in the archive.

`tb/export_envelope.py` checks the installed full `glbl.v` identity (1762 bytes, SHA-256 `6270251cf35e1fce3119fc79f8fb968912f7983027e43cf030409ba68f048936`) and its exact post-120-byte body (1642 bytes, SHA-256 `4d98d1c9f6176e36539aad193fd1df028baed0d4bbbdd71791bef453e3bcb334`). It accepts only one byte-identical body at EOF after a complete module and newline boundary. A capsule-free state exists only when explicitly requested by synthetic tests. A mutated, duplicated, reordered, appended, or alternate macro body is unsupported; the code never expands macros or parses `glbl` as bank logic. Input size is checked before slicing or decoding.

`tb/funcsim_structure.py` preserves the v6 lexer, `parse_text`, semantic classes, bounded expressions, primitive expansion, and all numerical literal rules byte-for-byte through the production reader. Only `read_export` changes: it uses a bounded raw read, asks the separate envelope recognizer for strict prefix modules and exclusion evidence, then performs the same `Expanded` construction. The prefix retains offset zero, so parameter literal spans still index the original raw export bytes. The recognizer rejects prefix tokens or escaped hierarchical names that explicitly name `glbl`/`GLBL`; `Expanded` and the unchanged graph binder continue to require exact reachable bank hierarchy, primitive, pin and net correspondence. The join records each excluded capsule with raw-file hash, exact byte offsets, installed-file identity and header offset; it rechecks raw identity when validating literal spans. The join default CLI still refuses actual input without a later gate.

The excluded body is retained by immutable installed-file reference, not treated as parsed functional logic. Its ROC_WIDTH is 100000 ps, TOC_WIDTH 0 ps, GRES_START 10000 ps, and GRES_WIDTH 10000 ps. It initializes GSR and PRLD high then lowers them at 100000 ps, initializes GTS high then lowers it after zero delay, and drives GRESTORE high from 10000 to 20000 ps. JTAG declarations and initial values remain in the exact bound body. UNISIM can use these globals implicitly even with no explicit bank instance. This source join checks static connectivity and explicit parameter correspondence only; a later mapping model must separately justify settled operation after startup and global reset/restore semantics. No initialized-memory, operating-timing, or board claim follows from this exclusion.

The original 19 synthetic v6 methods are retained. Eight new synthetic test groups cover exact capsule acceptance and raw literal spans, explicit capsule-free synthetic mode, byte drift, duplicate/changed macros, branch/directive rejection, malformed prefix boundaries, glbl references, and cap-before-split ordering. No test opens the eight raw exports through `read_export` or invokes actual `bind`.
