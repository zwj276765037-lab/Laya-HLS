## Independent capacity and address acceptance

Primitive count or nominal block bits are upper bounds until actual configuration and pin use are reconciled. Decode the legal word width/depth, active data/parity bits, cascade chains and port roles. Build the mapping from each `(bank, logical address, logical data bit)` to physical storage identity, physical location and bit, for the actual write path, and separately derive the read-selection mapping. Account for disabled write lanes, constants, replication, padding capacity and any unused parity. Explain every storage bit credited to logical capacity.

Evaluate the actual LUT truth tables and mux/FF or RAM cascade semantics. For all 20,992 valid addresses in every bank and all 16 logical data bits, establish that enabled writes target their intended storage, all logical words are representable, distinct valid logical cells do not alias, and enabled reads select the same written logical cell after the documented synchronous-read latency. Confirm low address bits and every upper decode bit, not just bit 14. Include the high interval and boundary transitions 16,383/16,384 and 20,991.
