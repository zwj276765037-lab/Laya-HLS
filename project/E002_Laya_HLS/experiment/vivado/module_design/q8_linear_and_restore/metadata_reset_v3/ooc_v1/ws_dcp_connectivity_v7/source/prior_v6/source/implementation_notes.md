# Ws v6 source implementation notes

The authoritative [v6 design](design.md) applies the reviewed [v5 design](prior_v5/source/design.md) to a fresh sibling. [prior_v5/manifest.json](prior_v5/manifest.json) records SHA256 and byte-for-byte copies of the v5 packet plus all fourteen maintained files. [v5_to_v6.diff](v5_to_v6.diff) is the literal maintained-file diff. The v5 contract, generated required-property Tcl, installed UNISIM semantics, DCP and XDC identities are inherited without modification.

The dormant extractor still opens the exact checkpoint once and exports ws_U, ws_8_U, ws_9_U, ws_10_U, ws_11_U, ws_12_U, ws_13_U, ws_14_U with the unchanged explicit funcsim flags and output caps. Its output root is rebound to fresh v6 paths. It retains raw DCP values and read statuses, including gaps, and treats structural extraction faults as terminal. The join first requires structural graph correspondence. It then rejects ERROR, TRUNCATED or unknown property status, and rejects MISSING with any nonempty raw text. Empty MISSING or empty OK is an unresolved DCP value that requires an explicit export for each required semantic setting. Nonempty OK must parse as a known literal and match every explicit export value and applicable width/signedness. All eight RAMB36E2 inversion fields still require explicit known one-bit overrides. Raw DCP and export values/spans remain separate evidence.

The structural parser accepts continuous wire/tri net aliases, named connections, finite concatenations and selections, escaped names and shared module definitions. It rejects reg/logic variable declarations and initializers, including ANSI and non-ANSI output variable forms. This avoids interpreting a one-time variable initialization as a continuous alias. Literal widths, digit counts, bus indexes and selected range sizes are checked before shifts or lists; source tokens, identifiers, hierarchy depth and total expansion also have explicit bounds. Unsupported syntax is terminal. The parser does not execute Verilog.

The default join CLI still refuses actual graph/export input. The 19 synthetic tests are tiny in-memory source checks. An actual export may reveal unsupported syntax or exceed these stop limits; such an event needs review, not automatic parser expansion. Source success does not establish Ws storage capacity, read selection, parity/cascade, reset/clock semantics, or routing.
