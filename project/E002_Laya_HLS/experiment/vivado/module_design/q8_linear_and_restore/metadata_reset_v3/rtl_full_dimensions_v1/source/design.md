## First pilot

The first matrix is production `scorer_fc1.weight`, K=1024, N=1024, group size 32, T=128, with original q/scale and `linear_120_baked_bias` bytes. Activation is the frozen R0 `marker_norm` B2/S128 checkpoint, selected batch 1 row 15; the complete expected output is the frozen `scorer_fc1_baked` row. The sequence on one cold DUT is LOAD_W, one-row RUN with selected-column/group trace enabled, then the same input RUN with trace disabled and fresh legal task/epochs. The two RUNs must check all 1024 F32 outputs, original A8/half scales, status and physical writes; trace-on checks all 32 groups for selected column 7. Later rows/families/faults have separate execution gates.

The physical static map has 341 distinct 4 KiB pages: descriptor 1, q0/q1 128 each, scale 16, AUX 3, activation 16, out0 16, out1 sentinel 1, observed 32. The map covers up to 16 selected rows but individual command address monitors will admit only their exact touched ranges. Actual nine AXI bundles and both AXI-Lite banks must be wired from generated pins, with the existing bounded endpoint and finite valid-hold adapter. Read-only observers record start/done, real issue/retire handshakes, PS dependency events, actual FP launches and AXI stalls. Aggregate `c_issued_2/c_retired_2` and constant FP CE/valid are only final totals or static levels, never counted as individual operations. Observer predicates, hierarchy paths, widths and source/schedule locations belong in a separate machine-readable binding manifest before compilation.

The addendum's three precision cases use the same real full matrix but copied, explicitly synthetic activation/AUX bytes. They are later source-only preparations: subnormal activation with amax bits `037e0000`, reciprocal-overflow activation with amax bits `00800000`, and zero activation with one copied baked-bias word `00000001`. They do not replace historical graph inputs or the first three-command pilot. Each needs an independent frozen intermediate/output oracle and a separate later runtime gate.

## Actual source mapping at the source-only checkpoint

`tb/materialize_scorer_pilot.py` binds the complete current BO and original GGUF tensor slices, checks the 32,768 original Q8 groups against both physical weight shards and scale BO, takes frozen `marker_norm` B2 row 15, and derives an independent full-1024-output R0 oracle before writing any fixture. It also builds all three descriptors, 341 mapped pages, full expected output/observed images, and the selected column-7 group trace. The script has not run.

`tb/test_q8_full_scorer.cpp` is the separate CPU leaf/TB source. It maps the original complete BO read-only, checks selected physical pages, invokes the unchanged HLS C++ top in one cold process for LOAD and two RUNs, then compares all 1024 F32 outputs and all 32,768 observed words for each command. `tb/build_cpu_leaf.sh` stages two separately compiled translation units, each with a compiler-generated `.d` dependency file; the later binding check rejects any active non-system include outside the frozen packet. The read-only source closure scans literal includes recursively and cross-checks the existing CSim `.d` records plus the 241-file HLS preprocessor record. `tb/run_cpu_leaf.sh` remains unexecuted.

`tb/generate_top.py` emitted `tb/q8_full_scorer_top.sv` from all generated DUT pins. The top uses the accepted bounded endpoint and AXI adapter, nine physical AXI pagesets, both Lite interfaces and the control/observer includes. `tb/q8_full_scorer_control.svh` programs and reads back all nine pointers, applies per-command AXI windows, checks same-edge done debt, dumps complete raw memories before assertions, and verifies full images plus dual-sided traffic accounting. It writes and flushes passive progress markers at command start and every 131,072 command clocks, including AP acceptance, TB phase, issue/retire counts, child request/completion counts and selected AXI byte totals. `tb/q8_full_scorer_observer.svh` samples the real top acceptance, issued tile and retirement predicates, representative PS RAM dependence, selected FP launch states, child request/completion markers, scalar states, and both sides of all five AXI channels. Child start edges are request markers, not independently proven child acceptance handshakes. Exact hierarchy, widths and predicates are listed in `source/observer_binding.json`.

`tb/prepare_runtime.py`, `tb/build_static.sh`, `tb/run_pilot.sh`, `tb/check_pilot.py`, `tb/make_source_packet.py` and `tb/verify_source_binding.py` define the later guarded stages and full raw-dump audit. The v3 source packet hashes the immutable generated 230-Verilog/108-DAT/seven-VHDL closure, installed simulator libraries, endpoint, model inputs, checkpoint pairs, CPU include closure and all new source before reviewer release. The four XSim runtime-mutable files are bound relative to `xsim.dir/q8_full_scorer/`, matching the accepted ACT snapshot layout. `rtl/README.md` points to the unchanged generated RTL; no RTL is copied or edited here. No numerical fixture, CPU binary or compiled simulation artifact belongs to this checkpoint.
