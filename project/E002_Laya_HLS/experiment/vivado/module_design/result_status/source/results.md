## 2. P0历史：条件性能、带宽与容量估算

### 结果大小与计时边界

| 项目 | B2计算/预算 | 说明 |
| --- | --- | --- |
| candidate有效数据 | 2×16×4=128bytes | 结果内offset128 |
| act有效数据 | 2×2×4=16bytes | 结果内offset256，区域预留64B |
| 头/详情/预留 | 头128B，详情从offset320后 | 完整结果预算4096bytes |

若串行发送完整4KiB到候选512bit接口，纯数据为4096/64=64拍，约0.427μs@150MHz。这不是端到端写回时间，还需地址、响应、互连等待、XRT同步和CPU读取；若只写部分区域则按实际流量统计。

完整kernel时间由已验证计时范围获取；本文不填写未实现的cycles计数。常驻请求分词/组帧/H2D/kernel/D2H/解码与冷启动分开记录，P50/P95与测试次数待实际运行及G6。


这些数据的证据状态均为推断/条件计算；已知shape/字节数来源于模型与原规格。它们不包含尚未明确的IP延迟、实际II、首填/排空、互连及背压成本，除非公式明确单列。性能承诺需要后续实现与同配置实测。
