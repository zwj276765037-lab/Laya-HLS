## Fixed experiment and source mapping

`rtl/` contains the same 32 SystemVerilog files as v1, byte-for-byte. `tb/axi_allocation_diag_test.sv`, `tb/build_static.sh`, DPI C/shared object, and runtime guard/helper are also copied unchanged. The top still creates seven `axi_env#(64,4,8,3,1)` and seven 65,536-byte patterned memories, with identical callbacks and latency. Both modes use one snapshot and seed 1, run exactly 100,000 postreset clocks, and sample the same checkpoints. Traffic starts at clock 10,000, sends 1,024 ordered single-byte writes and aligned 32-bit readbacks on qkv0, must drain by clock 90,000, and ends with complete expected-versus-backing comparison across all seven pages. Idle keeps master VALIDs zero and response READYs one. All original assertions and distinct PASS markers remain.

`tb/phase_axi_monitor.sv` now declares one `clocking sample_cb @(posedge clk)` with `default input #1step`. It samples reset and every AW/W/B/AR/R handshake signal and relevant metadata, including BID/BRESP and RID/RLAST/RDATA/RRESP. Its `always @(sample_cb)` updates fixed counters/rings and the last B/R tuple from the same stable pre-edge image. `consume_read` takes sampled RLAST; sampled AR metadata handles same-edge AR/R. Fixed first-B/R metadata messages omit payload. `tb/axi_allocation_diag_top.sv` connects those fields, removes its separate `always @(posedge clk)` response latch, and checks the monitor's last tuple after the corresponding count advances. Stimulus remains on negedge and held until the monitor records a real handshake. The top's existing one-picosecond post-edge observation delay is retained pending the static build/runtime validation of scheduling.

The exact v1→v2 delta is `source/stable_sampling_v2.diff`, and `source/source_binding_packet.json` binds the copied source, compile closure, exact planned commands and guard policy. Only the new static build may follow consolidated Astra source review. The static build limit is 16 GiB owned RSS, 300 s, four CPUs, nice 19, idle I/O, 192 GiB host floor, 0.2 s guard samples. Runtime needs a later snapshot gate: idle then traffic, each fresh, 4 GiB/90 s/100,000 clocks with the same policy. Any fatal, guard trigger, nonzero exit, incomplete endpoint or assertion stops the sequence.

The experiment isolates AXI VIP/memory behavior without an Attention DUT. Its RSS contrast cannot identify the simulator allocator or establish a full-DUT memory bound.
