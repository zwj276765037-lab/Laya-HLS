## Physical image and independent checking

Each logical image contains all3 planes ×16 heads ×64 rows ×64 F32 =786432 valid bytes. Per-shard effective prefix stays10240064 bytes, while FullMemory logical capacity remains12MiB/shard and host arrays retain that full size. Host checker verifies all host bytes; RTL can claim only the actual modeled prefix. Layout in F32 indices is `((((plane*2+batch)*8+head/2)*1024+row)*64+d`, shard=head%2, byte offset4*index. Expected raw source is row-major `[64,3072]`, byte position `4*(row*3072+plane*1024+head*64+d)+byte_in_word`.

Independent physical checker derives plane=index>>20, batch=(index>>19)&1, local_head=(index>>16)&7, row=(index>>6)&1023 and d=index&63, then head=2*local_head+shard. A byte is source data only for plane<3,batch0,row<64 and its actual completed row mask; all other prefix/host-tail bytes must be0xa5. Do not call qkv_address in this second checker. Hash and record raw tensor, expected full image, actual host image, masks, request and package identities. A negative missing-row/plane image retains sentinel there and clears only those receipt bits.
