## Scope and mapping

The sole functional-source change in [the V7 top](attention_preloaded_slice.cpp) moves the existing function-local `using namespace laya::full;` to the first line inside `attention_preloaded_slice`, before the `#ifdef __SYNTHESIS__` interface/reset pragma block. It removes the prior occurrence below that block, leaving exactly one directive. The HLS reset pragma still spells `#pragma HLS reset variable=metadata_initialized`. The [V6 first-failure archive](../../v6_metadata_reset/runs/hls_synthesis_v1/actual_result_evidence.json) shows the HLS frontend at line 448 could not resolve this unqualified namespace-static identifier while the directive was below it. The V7 move gives ordinary lexical name lookup visibility at the pragma without changing executable statements.

`attention_preloaded_slice` retains the eight call arguments: scalar `command`, const descriptor, mutable IO, const AUX, two mutable QKV banks, mutable Attention output, and mutable observed report. The source keeps the same seven AXI master bundles plus the control bundle, shapes, address maps, ordering, error behavior, and reset helper. On first call after hardware reset, the false scalar `metadata_initialized` triggers `reset_metadata` before memory binding or command parsing; the helper rewrites persistent metadata, not numeric payload. The CPU-only hook remains excluded from synthesis. Physical pin behavior and payload RAM reset cones require generated RTL review.

The included production Controller, 25 official synthesis translation units, model package, original fixture and the copied V6 testbench are unchanged. The copied ABI and testbench are byte-identical; the config changes only local V6 paths to V7 paths. The CPU launcher is copied byte-identically and computes its own local module root. The frozen V5 original references and fixtures remain at their original paths. The V7 evidence archive contains exact V6 preimages and identities before adaptation.

## Validation boundary

The [source checker](make_source_packet.py) defaults to read-only, verifies the gate and frozen preimages, exact top move, single pragma and direct function-body scope, token-identical top after removal of the moved directive, path-normalized config identity, 25 unique official synthesis units with Controller once, copied ABI/test files, exact V6 dependency records, and the dormant execution plan. `--write-packet` only writes a new source packet and source diff after all checks pass. It invokes no compiler, CPU test, CSim, HLS, Vivado or XSim.

V6 strict CPU and CSim numerical evidence can be inherited as a source-semantic argument only after independent exact-diff review; neither test is claimed as executed for V7. A future single HLS attempt has a separate gate. Any new frontend or implementation failure must be archived and reviewed before further source changes or retry. Physical reset, pointer CSR rebind, old RUN rejection, payload retention and fresh numerical BEGIN/RUN remain separate RTL obligations. The host must invalidate old receipts across reset and bind a fresh generation; the local ticket restart cannot itself prevent an ABA identity collision.
