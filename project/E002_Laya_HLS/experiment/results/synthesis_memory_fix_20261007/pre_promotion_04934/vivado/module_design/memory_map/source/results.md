## 2. P0历史：条件性能、带宽与容量估算

### 容量与帧尺寸分开计数

| 项目 | 可复算值 | 说明 |
| --- | --- | --- |
| 主张量逻辑容量 | 4×8+24+8+41+20.5+0.125=125.625MiB | Decision32MiB复用Wi空间 |
| 模型BO预算 | 64+192+192+32+8=488MiB | 在512MiB总模型预算内；不是payload大小 |
| 工作区BO预算 | 32+32+16+16+48+24+16=184MiB，另io32KiB | 在192MiB预算内；不是每次PCIe流量 |
| B2/S128请求 | 核心1448bytes，帧1856bytes | payload offset320/1344/1600/1728/1792 |
| B2/S1024请求 | 核心10408bytes，帧10816bytes | 5目录项后按64B逐张量对齐，仍小于16KiB |

模型移除可由逻辑生成的slide_bias表后的有效payload为448921352bytes；full/sliding RoPE的四张位置表仍须保留。物理bank可用容量、地址检查器代价和生成逻辑II尚未测；本模块负责计算地址，不应再次计入HBM或算子缓存容量。


这些数据的证据状态均为推断/条件计算；已知shape/字节数来源于模型与原规格。它们不包含尚未明确的IP延迟、实际II、首填/排空、互连及背压成本，除非公式明确单列。性能承诺需要后续实现与同配置实测。
