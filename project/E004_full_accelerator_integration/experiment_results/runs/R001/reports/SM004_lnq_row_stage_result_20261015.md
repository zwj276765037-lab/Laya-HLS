## 行为与独立比较

薄顶层在首个真实 LN `out_valid` 时先让 Q start 接受，随后才接收首个 LN 元素；16 个 LN F32 握手填满唯一 512bit pack 后送 Q。Q 的 64 个 half 和 32 个 FP16 scale 写入隐藏的 q0/q1/scale 32 组暂存；LN/Q 成功 done、64 half 与 32 scale 覆盖、Q 真实 `physical_debt_zero` 及 pack 空同时成立才置 `row_valid`。同步单响应读口允许任意顺序和重复组；行释放等待响应实际消费，最终 done 保持到握手，之后才接下一命令。没有 portal/owner/lease 或外部 AXI。

AT121 冻结同一顶层完整局部回归：P1 历史 `abi_replay S128 B2` 的 `wi_ln_rows1` gamma0 与 `qkv_ln_rows1` embedding gamma1 由原始 input/gamma 输入真实 LN，LN 全部 1024 输出及三项统计逐位对照保存的独立核验夹具，Q 返回每组 256bit int8＋16bit FP16 scale 逐位对照原 `dut.q8.bin` 的 32×(LE16 scale＋32B Q) 布局。顺序 gamma0→gamma1→gamma0 无 reset，再经过错误恢复与 reset 后各一条 gamma0，共五条正常行；其中 AT121 的 reset **未证明本次 Q 在途**，更正见下文 AT122/123。每行倒序读32组并重复读17、0组；读响应阻塞三拍保持，行持有时新命令拒绝，release 与新读同拍优先。gamma1 样本在共享 Q 输出握手线上受控暂停 42cycle，Q 输出/标签在阻塞期间保持，最终数值仍逐位 PASS。TB 的受控 force 同时作用于 Q 接收端与顶层计数的同一 ready 线，不代签外部总线反压。
