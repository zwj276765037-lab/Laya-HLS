## 1. 首版系统职责与调用边界

| 子图 | CPU 职责 | FPGA 服务及接口形状（S/K/N） |
| --- | --- | --- |
| 输入 | 分词、mask/position、Embedding、embedding LN | 接收 FP32 主线输入 |
| Encoder Attention | 第 0 层直接使用 embedding LN；其余层 pre-LN；RoPE、QK、有限 mask、softmax、AV | QKV：128/1024/3072；WO：128/1024/1024 |
| Encoder FFN | pre-FFN LN、前后 residual、权威 hidden/skip | Q→Wi（128/1024/5248）→GEGLU（2624）→Q→Down（128/2624/1024） |
| Encoder→Decision | final LN、type embedding 选择与广播相加 | 无新增单独小算子调用 |
| Decision Attention | LN、完整 Attention、residual；无 RoPE/sliding | 带 bias QKV 与 WO，形状同上 |
| Decision FFN | LN、residual | Q→FC1+bias（128/1024/4096）→ReLU→Q→FC2+bias（128/4096/1024） |
| 尾部 | 全部 16 个 scorer 槽、marker LN、两次 scorer bias、统计、ACT、final18 | 首版不承担尾部 |

每层是 QKV、WO、完整 FFN 三个粗粒度服务。它们可共享一套矩阵引擎和 bitstream，不要求三套阵列。CPU 不下载 partial sum，不按 group/tile 发命令；FPGA 内部完成量化、整数 dot、group32 FP32 恢复、有序累加、bias 和打包。

CPU 保留权威 hidden 和残差来源，FPGA 返回增量。激活边界 FP32，QKV 使用明确布局的打包缓冲。主线权重初始化后驻留 HBM，Embedding/尾部权重留 CPU；HBM 常驻不代表片上工作集已经命中。FFN 宽中间量不得跨 PCIe，可用板端 HBM 暂存或片上行窗口转发；不强求全量驻片上。

Host 描述符至少包含请求/模型/数值版本、层号/模式/形状、输入输出范围、权重/bias 引用；固定模型允许预建描述符和复用 XRT 对象。输出只有在计算、真实写响应及所需 D2H 完成后才能被 CPU 消费。无需复用旧 13BO、portal、token 体系的全部对外接口。

## 2. 高性能数据通路是主要工程工作

1. **供数与算力一起设计。** 用完整 S128 的 QKV/WO、Wi/Down 和 Decision 形状选择并行度，列出 A/W 每拍需求、bank 端口、HBM 通道和工作集容量。以持续有效 MAC/cycle 判断吞吐，不能只报峰值 lane 数。
2. **重叠装载与执行。** 采用有界双缓冲/多槽、预取和突发读取，使 A/W 装载、量化、整数计算、恢复及写回尽量重叠。权重跨多行复用；记录换槽、端口冲突与短突发损失。允许重做旧 bank 布局、缓存大小、矩阵服务和父控制，不为兼容旧串行 FSM 牺牲主性能。
3. **提高恢复与累加的有效吞吐。** 不同 row/列的独立输出可交错以覆盖浮点流水延迟；每个输出仍保持原 group 顺序。恢复、累加、bias、写回的接收速率须匹配整数阵列，不能用增加 dot 阵列掩盖后端瓶颈。
4. **实现完整 FFN 的驻留与复用。** Wi/Down 共用阵列时按真实依赖切换；融合减少 Host 往返，不等同两矩阵同时计算。GEGLU 完整 group32 结果形成后按原规则再量化，保持全部 FP32 舍入。缓存安排兼顾 Wi 和 Down 工作集及多行复用。
5. **CPU 热路径也要优化。** 实现编译后端，按独立输出/归约节点使用 SIMD 与固定核数多线程，减少 QKV 布局复制和临时分配。检查 FMA、重排、FTZ/DAZ 及数学函数等价性；Python 独立参考保留作 oracle，不作为主要性能对照。
6. **及早确认物理代价。** 初版矩阵阶段就验证可综合性、资源与关键路径，系统合并后核联合资源/Fmax。目标频率、阵列规模、HBM 可用带宽和缓冲预算由证据确定，不能默认旧 1024 MAC/cycle 或假设 150MHz 足够。
7. **有界请求重叠。** 先形成正确的完整请求路径；随后按实测瓶颈实现两个独立上下文，让 CPU Attention 与另一请求就绪矩阵重叠。显式计入排队、权重换入和缓冲占用，不用吞吐改善代替单请求延迟改善。

首阶段应形成一张可持续更新的性能表：矩阵规模/目标服务周期、A/W 带宽、恢复与写回速率、缓冲字节、资源与目标时钟、测得瓶颈和下一改动。未测列标 UNKNOWN；阶段指标在测量后冻结，不能在失败后下调目标并称优化成功。预算建立与 CPU/RTL 实现并进，不把完整性能预测做成长期前置研究。

## 3. 数值语义与执行顺序

保留 B1/S128、28 Encoder＋2 Decision、原权重与完整尾部。Encoder layer % 3 == 0 使用 full，其余使用原 sliding；Decision 无 RoPE/sliding。Wi 的配对是同一行前 2624 列与后 2624 列，不是相邻列。scorer 先 baked bias 再独立 scorer bias；ACT 使用最终 Decision 原始 hidden[0]＋四统计量；final18 前 16 项是 masked logits。

Q8 group32 amax/scale、量化舍入、scale 乘积与恢复乘法的分别舍入、按 group 累加、LN/Attention 的规定归约、GELU/tanh 和尾部顺序保持。物理融合不省略原中间舍入；不默认使用 FMA 或不同归约树。全部 128 token/16 槽计算，不根据当前有效项裁剪。数值容差沿原明确合同；没有容差授权的输出按原逐位要求验证。

新执行合同允许有限的未来块预读和独立输出在途，替代旧路线“后续 tile 零读取”和逐小块全局排空限制。阶段设计必须给出窗口上限、buffer 生命周期、按逻辑顺序的结果/首错提交和真实 AXI 排债：数值逻辑首错不取决于物理先返回者，失败不得发布成功，越界访问与跨请求污染禁止。对旧测试中“零后续读取”的断言按新版执行合同另建测试，保留旧结果，不能冒充原断言仍通过。

预取改变物理传输次序时，协议/传输错误与数值错误的适配及优先级须在新服务 ABI 中明确；不沿用旧字段而默改含义。无需把所有历史取消、重入、内部停顿排列作为新算力设计前置；本版必验地址隔离、有限反压、真实完成、错误排债、共同复位和后继请求安全。

## 5. 性能账与验收口径

已核静态工作量：主线 120 矩阵、47,143,976,960 MAC；量化权重与 scales 391,331,840 B，另有 73,728 B bias。完整图另外两次 Q8 在 CPU 尾部。依据为[矩阵清单](../../source/feasibility_20261014/v4/matrices.csv)和[预算源表](../../source/feasibility_20261014/v4/budget.json)，旧表中的延迟预测不作为新系统测量。

| 静态 FP32 激活边界 | H2D | D2H | 总量 | 依赖服务段 |
| --- | ---: | ---: | ---: | ---: |
| 四矩阵独立卸载 | 84.875 MiB | 150.75 MiB | 235.625 MiB | 120 |
| 本任务 QKV/WO/完整 FFN | 45 MiB | 75 MiB | 120 MiB | 90 |

融合少传 115.625 MiB（约 49.1%）；此为有效 payload 账，不是实测加速比。90 是服务段数，不是单向 DMA 或必然的 API 次数。初始化权重、对齐、驱动、复制与同步另计。可选 hidden 驻留方案的 60.56640625 MiB 包含初始输入和紧凑尾部出口，前提是 final LN/type add 也在设备；不属于首版已实现收益。

主线仅按 1024 MAC/cycle、假设 150MHz 的理想整数计算就约 307ms，尚未计恢复、CPU 和传输。这是设计警示，不是实测或批准的频率/延迟目标；需要依据资源与供数重新选择持续算力。

每个代表服务同时记录总周期、有效计算、A/W/恢复/部分和/写回等待、真实字节、工作集换入、资源和频率；重叠区间不能重复累加。系统记录 CPU 各子图、Host 布局/提交、H2D、kernel、D2H、同步与尾部，最终用统一时钟实测请求开始到 final18 可读的时间。

对照统一模型/输入/B/S/候选数、数值版本、CPU 核数、预热、权重驻留、并发及计时起止。冷启动和热请求分列；报告样本数、P50/P95、QPS、排队延迟及波动。单请求串行依赖不能简化为 CPU 与 FPGA 时间取最大值。CPU/GPU 对比只有同口径实际测量后才能声称加速。

## 6. 完成与不通过的判定

- **正确性：** 至少完整 Encoder、完整 Decision、完整请求及顺序重复请求通过独立参考；包括特殊值、有限反压/页界、失败/复位与后继请求。阶段正确性不能代签整模；现有独立 gold 不足的范围标缺口并补独立依据，不能观察 DUT 后写 gold。
- **矩阵/FFN：** 全服务含量化、恢复、bias、真实访存与写回；FFN 实际宽中间量留设备。融合 FFN 要在相同边界计入传输后优于全 CPU 与拆分对照，达不到时列为待优化，不能以流量公式宣称通过。
- **端到端性能：** 对合理优化且数值兼容的 CPU 全请求基线，取得可重复且超过噪声的延迟与持续吞吐收益。两项分开验收；局部 MAC 利用率提高而系统无收益时，性能仍未完成。具体毫秒/倍数尚未指定，早期数据用于形成阶段预算，不编造硬门槛。
- **物理与部署：** 同版本完整核及平台适配容量、资源、路由时序、实际运行频率有证据；HLS 估计、OOC、全设计 P&R、实板数据分列。无板卡不代签实板或完整性能目标。
- **可复现：** 模型/输入/工具/代码身份、命令、原始结果、计量起止、完整性与适用范围可追溯；失败、COST_STOP、未知费用原样保留。

结果至少分别给出 functional、physical、latency、throughput、board 五项结论。代码写完或文档齐全不等于 M006 完成。
